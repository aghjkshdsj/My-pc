Experimental ARM64 Steam **Metal** development preview for iPhone. Download the real **SomethingPC-SteamARM64.ipa** from Assets and sign it with your sideloading tool.

Update the existing My-pc app, restart it, and open **Library → Apps → Steam ARM64**. Before startup select **Graphics → Metal (experimental)**, enable JIT and open Steam. A saved Software choice is preserved and shows a **Use Metal graphics** button. Software remains the recovery option. CPU cores default to all available, normally six on iPhone 15 Pro Max; the Linux desktop is 1280×800. The pointer, touch/trackpad controls and CPU/RAM/display-FPS monitor are included.

This candidate targets the long delays reported with Metal preview 11. GPU screen updates are combined into at most one full readback per display tick; the final update is delivered even when the guest stops drawing. Mouse motion retains only one pending position when the VM is busy, allowing queued clicks and releases to proceed. The disk uses a separate IOThread with guest flushes preserved, and the shared JIT translation cache increases from 128 to 256 MiB. **These changes need a new physical iPhone performance test; no speed multiplier or game compatibility is claimed.**

This backend uses virgl → ANGLE → Metal. The owner reported a working virgl renderer/readback check on iPhone with preview 11, but very poor responsiveness and a Linux Steam process crash. The new release gates require an actual guest GL renderer/pixel-readback check, Steam CEF virgl compositing/WebGL, measured CEF click/animation-frame response and QMP input acknowledgment, display delivery, persistent storage and clean shutdown on a hosted Mac. CI uses the same minimal framework closure as the IPA, including dynamically loaded ANGLE EGL/GLESv2 providers and their resources. Missing-provider controls must return an error without SIGABRT. The IPA archive must contain both providers with valid iPhone binaries and required exports. Mac measurements do not predict iPhone performance.

The overlay distinguishes **Software selected**, **Metal requested · unverified**, **virgl → Metal verified**, and a software fallback/readback failure. The verification refers to the guest GL driver and a rendered pixel; it does not prove that every application, Steam CEF or a game's Vulkan renderer uses that driver. GPU utilization is unavailable. **Performance** shows the last VM input acknowledgment time; this is distinct from Steam drawing its response. **Share graphics report** exports build/backend/hardware diagnostics, acknowledgment time and thermal state without account details or full logs.

A checksum-verified boot update changes only three reserved My-pc startup scripts, with backups. It preserves the existing Linux disk, downloaded Steam client, account and games. The installed kernel must match the update; a mismatch refuses Metal and leaves Software usable. If Metal startup fails, restart My-pc and choose Software. Do not reset the Linux installation.

Steam still downloads directly from Valve. Existing Steam data should remain when updating the same signed app; deleting the app deletes its sandbox. New setup needs approximately 13 GB free. This is a JIT sideloading preview, not the separate JIT-free product or an App Store build. Audio, Windows-game translation/Vulkan and gaming performance remain unfinished. Corresponding runtime sources and IPA checksum are attached.
