## Concrete correction

Pinned Mesa 26.2.2 `src/virtio/vulkan/vn_physical_device.c` rejects external
DMA-BUF image format queries whose tiling is not
`VK_IMAGE_TILING_DRM_FORMAT_MODIFIER_EXT`. The previous image diagnostic used
`VK_IMAGE_TILING_LINEAR`, even though the renderer has an explicit linear DRM
modifier adapter. This revision corrects the requested contract within the same
Linux/Venus/Metal architecture.

The new production query helper requests RGBA8/2D/transfer destination with
DMA-BUF external memory, explicit DRM modifier tiling and `DRM_FORMAT_MOD_LINEAR`.
It preserves the actual Vulkan result and requires exportable compatible memory,
720p extent and single-sample support. Image creation uses the same one-modifier
list. The guest queries the image's actual modifier, rejects anything other than
linear, and queries memory-plane-0 layout. Exact stride/offset/allocation bounds,
GPU producer completion, external queue release, resource identity, native buffer
alias, independent pixels, consumer completion and cleanup remain mandatory.
Native/desktop validators now reject wrong or missing modifier metadata.

Khronos specifies the
[modifier capability query](https://docs.vulkan.org/refpages/latest/refpages/source/VkPhysicalDeviceImageDrmFormatModifierInfoEXT.html)
and [matching image creation list](https://docs.vulkan.org/refpages/latest/refpages/source/VkImageDrmFormatModifierListCreateInfoEXT.html).
The source review uses the exact hash-pinned Mesa archive, not a newer branch.
An advertised extension does not establish format support or imported pixels.

## Device procedure and remaining work

Install with iLoader. Close and relaunch the app, enable JIT through StikDebug
using `universal.js`, return and run the ARM64 JIT check. Run **Linux image import
gate first** in that fresh process. Keep the app foreground for up to three
minutes and share the device report. If it closes, reopen and share saved logs.
Each Linux boot requires a new process. No report is automatically uploaded.

Only actual guest/native image events, pixel/fence/resource correlation and safe
cleanup can accept phone import. This diagnostic still uses serialized producer
fences and two bounded full-image native readbacks. Moving CAMetalLayer output,
bounded asynchronous frame ownership, WSI/compositor/OpenGL, rootfs/services,
