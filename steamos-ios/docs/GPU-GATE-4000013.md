## Source correction

The preliminary `Guest/gpu_kernel_probe.c` request used texture target 2 and
bind flags 0. The pinned renderer's `vrend_renderer.c` classifies bind 0 as a
buffer request and rejects a non-buffer target. The corrected request uses
`VIRGL_BIND_RENDER_TARGET`'s fixed protocol bit 1, numerical value 2. The emitted
driver receipt records that value. CPU-mapped pixels and a completed transfer
ioctl alone cannot independently verify native resource creation or GPU drawing.

The corrected source-built Linux kernel/initramfs passed hosted ARM driver
positive and missing-device controls in run 37095310379. The complete Mesa/Venus
runtime passed Linux ABI and both 2D-only/missing-GPU Vulkan rejection controls
in run 37095653651. It preserves the exact external DSO/source/license closure.
The new Image and full runtime initramfs are pinned by size and hash; previous
kernel, guest and renderer receipts remain saved separately for build 4000012.

## Failure visibility

Native renderer run 37095310400 and QEMU run 37095545014 compiled actual ARM64
iOS libraries. The corresponding-source archives retain original files, patches
and recipes. Failure diagnostics record real results without changing allocation
policy or returning success for a failure:

| Marker | Evidence provided |
|---|---|
| `MPC_GPU_ALLOC_FAIL` | Anonymous-file allocation stage, byte count and saved errno |
| `MPC_GPU_SHMEM_FAIL` | File/map/resource-table failure and size; errno only when meaningful |
| `MPC_GPU_BLOB_FAIL` | Renderer context lookup or get-blob failure, context/result/flags/size |
| `MPC_GPU_CONTEXT_CREATE` | Actual renderer context creation result and capset; QEMU checks the result |

QEMU guest-error logging is enabled. The normal **Share device report** now
includes the host `engine-output.log` tail, capped at 65,536 bytes with its
file size, captured size, truncation and encoding recorded. The full saved
diagnostic export remains available on normal completion and after reopening
an interrupted test. Empty, missing or partial output does not count as success.
No automatic log upload is added.
